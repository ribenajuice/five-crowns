Place, time, and the filters: mockups for sign-off

Every screen below reuses Stage 1–3's components and tokens exactly — no new colour, no new type scale, no new shape beyond what's called out explicitly. This is the last stage of Milestone 3: after this, the board carries thirteen records and the catalogue is complete. Data is realistic and invented (Player A–E, per the house rule on mockups), continuing the same archive the Stage 2 and 3 mockups used (now 22 games, one venue added: "Player E's"). Chips: New this stage Unchanged from earlier stages.

Open question 9 is already settled. The founder confirmed (c) — both a venue page and a filter on 2026-09-15 (docs/DECISIONS.md), before this document was written. Nothing below is conditional the way Stage 2's nemesis wording was; criteria 260–261 are built exactly as specced.

Criteria 256–258

Player page: a new "By venue" section

Sits directly below Stage 3's "Best and worst game" section, above the player's own games list — nothing above it moves. The containment invariant (criterion 258): 6 + 2 + 1 = 9 — Sam's own games-played total from the headline stat block at the top of the page. This is what makes criterion 251's narrowing ("a game with no location is in no venue's numbers") provable rather than just asserted: nothing is missing, nothing is double-counted, and the unlocated game is visible in its own row rather than silently dropped.
"No location" never links anywhere — plain bold text, not an EntityLink. It has no venue page, holds no home advantage, and never appears on the places index (criterion 251). Colour is never the only signal that it's different from a real venue row — the label itself says so.
Criteria 259, decision on PlaceRow

Places index: rows become links, and gain an average

Stage 3's PlaceRow was deliberately not a Link — there was nowhere for it to lead. Now there is. The whole row opens the venue page; the pencil stays independently tappable via its own hit slop, the same "stretched link plus a layered control" construction GameRow already uses for its roster name.
