# Fixtures — deliberately not in this repository

`docs/` refers to `fixtures/sheets/` — two photographs of real, finished Five Crowns
scoresheets, with a founder-verified transcription in `fixtures/sheets/GROUND-TRUTH.md`.
They are the reference corpus for the Milestone 0 reading spike and the acceptance test
for Milestone 1.

**They are not committed, and should not be.** This repository is public; the photographs
show a private notepad and the real first names of the people who played. The directory is
listed in `.gitignore`.

The files live on the founder's machine at this path. Anyone working on the reading step
needs them supplied directly — they cannot be recovered from this repository.

Player names in `docs/` are anonymised to Player A–E for the same reason. The scores are
real; only the names were changed.
